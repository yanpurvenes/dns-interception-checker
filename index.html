🧪 Полный низкоуровневый тест сокетов (UDP:53, DoT:853, Гонка пакетов)

Браузеры изолированы от прямого создания UDP-пакетов на порт 53. Для детекции флага AA в NXDOMAIN, фиктивных IP (192.0.2.1) и гонки пакетов ТСПУ запустите скрипт через терминал:

curl -sSL https://raw.githubusercontent.com/yanpurvenes/dns-interception-checker/main/check_dns_interception.py | python3

Что проверяет консольный скрипт:

1. Флаг AA в NXDOMAIN Детектирует фальшивые ответы от оборудования ТСПУ, которое выдает себя за авторитетный сервер чужого домена.
2. Гонка пакетов (Packet Racing) Фиксирует приход двух ответов на 1 запрос: мгновенная инъекция цензора + легитимный ответ от резолвера.
3. Перехват фиктивных IP Отправка UDP:53 запроса на 192.0.2.53. Если ответ пришел — провайдер перехватывает ВЕСЬ 53 порт.
4. DoT:853 Handshake Прямая проверка блокировки TLS порта 853 и фильтрации SNI зашифрованного DNS.

🌐 Chrome / Brave / Edge / Yandex

  1. Откройте Настройки → Конфиденциальность и безопасность.
  2. Выберите Безопасность → Использовать безопасный DNS-сервер.
  3. Включите режим «С указанием поставщика».
  4. Укажите пользовательский DoH URL (например, https://dns.adguard-dns.com/dns-query или Cloudflare).
  5. Включите ECH в chrome://flags/#encrypted-client-hello.

🦊 Mozilla Firefox (Максимальная защита)

  1. Откройте Настройки → Приватность и защита.
  2. Прокрутите вниз до раздела DNS поверх HTTPS.
  3. Выберите «Повышенная» или «Максимальная защита».
  4. Укажите надежный DoH провайдер (NextDNS / Cloudflare / AdGuard).
  5. Firefox автоматически активирует ECH (Encrypted Client Hello).

🍏 iOS / iPadOS / macOS

  1. Установите официальный профиль шифрованного DNS (DoH/DoT).
  2. Или используйте приложения AdGuard, NextDNS или 1.1.1.1.
  3. На macOS в настройках сети: Сеть → DNS → добавьте DoH профиль.

🤖 Android (Private DNS)

  1. Откройте Настройки → Сеть и интернет / Подключения.
  2. Выберите «Персональный DNS-сервер» (Private DNS).
  3. Укажите имя хоста: dns.adguard-dns.com, one.one.one.one или dns.quad9.net.
  4. Весь трафик приложений будет шифроваться по TLS (порт 853).

🛡️ Утилиты обхода ТСПУ (DPI Bypass)

  • Zapret / GoodbyeDPI / ByeDPI: фрагментируют SNI и обходят сигнатурный анализ ТСПУ.
  • Amnezia VPN / VLESS Reality: маскируют весь трафик под легитимный HTTPS трафик зарубежных CDN.
  • DNSCrypt / dnscrypt-proxy: локальный шифрующий прокси с поддержкой анонимизированных релеев (Anonymized DNS).

⚠️ Что делать, если DoH блокируют?

  • Используйте DoH по прямому IP без SNI (например, резолвинг через нестандартные порты).
  • Включите ECH (Encrypted Client Hello) в браузере.
  • Настройте персональный DoH прокси на своем сервере (AdGuard Home / Pi-hole / DNS-over-HTTPS).
